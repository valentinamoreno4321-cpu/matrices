# Operaciones con Matrices - Programación I

## Descripción
Programa modular en Python que permite ingresar dos matrices y realizar operaciones matemáticas entre ellas: Suma, Multiplicación, Producto de Hadamard y Producto de Kronecker.

## Estructura del Proyecto
- `main.py`: Punto de entrada y control del flujo.
- `menu.py`: Manejo del menú interactivo.
- `entrada.py`: Lectura, validación y visualización de matrices.
- `operaciones_matrices.py`: Lógica matemática de las operaciones.

## Requisitos
- Python 3.6 o superior

## Cómo ejecutar
1. Abra una terminal en la carpeta `proyecto_matrices/`.
2. Ejecute el programa principal:
   ```bash
   python main.py
